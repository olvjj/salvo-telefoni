# Salvo Telefoni

Nedlastinger for **Salvo Telefoni** — programmet som lar deg ringe kundene dine rett fra
[Salvo](https://salvo.no) gjennom din egen mobil.

Dette repoet inneholder ingen kildekode. Det finnes bare for å holde de nedlastbare filene,
som ligger under [Releases](../../releases).

## Last ned

Gå til **[salvo.no/salvosoftware](https://salvo.no/salvosoftware)** for nedlasting og
veiledning.

## Hva programmet gjør

Kobler CRM-et til mobilen din over Bluetooth, slik at «Ring» i Salvo ringer opp uten popup —
og Salvo får ekte ringetid og taletid tilbake.

Helt frivillig, gratis for Salvo-kunder, og finnes for Windows 10 og 11.
